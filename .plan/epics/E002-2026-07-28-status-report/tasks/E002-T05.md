# E002-T05: `DecisionRecord` component

**Wave 2** · depends on T04.

## Goal
A reusable block that renders a decision with its context, the option taken, and — crucially — the
**superseding** relationship. This is the device that carries the Decision-1 → Decision-2 reversal.

## Acceptance
- Props: title, date/version, context, decision, trade-off, and an optional `supersedes` link.
- Renders the reversal legibly (e.g. Decision 2 visibly supersedes Decision 1).
- Uses only re-themed primitives (T04) / `design.md` tokens.
